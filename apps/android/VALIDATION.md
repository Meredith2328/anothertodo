## 功能验收

- 触摸新增任务、实时输入预览、逐项编辑、多行备注、完成、删除、取消与重新打开。
- 重复任务生成下一次记录，保留原有完成历史。
- 父子关联、连同子任务完成、整次撤销、连续三次撤销与归档事务撤销。
- 查询语法、备注检索、项目与标签、统计及详细统计。
- 批量选择、取消和撤销。
- Android 系统文件创建、文件选择、JSON 导入、完整备份内容与系统分享界面。
- 通过真实 Git HTTP 服务进行认证、推送、拉取和首次克隆已有仓库。
- 两端并发新增、同一任务修改冲突、较新修改优先、删除优先于编辑。
- 首次同步时保留手机本地任务，读取已有归档、父子编号和备注。
- 应用离开前台并终止进程后，由 Android AlarmManager 实际显示系统通知，随后确认投递状态已持久化。
- 真实 SMTP 服务器验证邮件认证、收件人、邮件内容格式与后台邮件提醒。
- 中英文界面、系统深色模式、正式 APK 安装、原生触摸操作和进程重启后的数据保存。
- 逐行批量添加、同批前向引用、候选点击确认、标题中的依赖识别、自动保存、关闭前保存及循环错误后的继续编辑。
- 日历、周历、月历、重要度、四象限、选中日期新增任务、长标题布局和完成方块开关。
- 依赖阻塞期间保持提醒未投递，终止进程后保持阻塞；完成前置任务后，实际释放并投递到期系统提醒。

## 性能与检查

设备端实际导入 1,000 条任务，总任务记录为 1,010 条。通过触摸导航显示列表并等待两次浏览器绘制完成，耗时 481 毫秒；包含输入与等待查询结果的备注检索耗时 291 毫秒。测量包括验收工具通信与界面等待。

桌面版本 22 个测试文件、197 项测试通过，包含 10,000 条依赖链校验、循环拒绝、批量事务与撤销、归档及删除优先级。桌面与 Android TypeScript 类型检查、ESLint、桌面构建和 Git diff 空白检查通过。Android 运行依赖的 npm audit 检查为 0 项漏洞。

设备测试脚本、报告和截图位于 `tests/` 和已忽略的 `test-results/`。构建与操作说明见 [README](README.md)。
