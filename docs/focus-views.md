# 聚焦视图与显示设置

清单区按 **3 全部 / 4 近期 / 5 接下来一小时**，或按 **f** 循环切换。鼠标也可点页签。输入中按 **Ctrl+V** 切换，草稿和编辑目标会保留。视图记在 config.toml，重启后恢复。

近期是今天至配置的 week_days 天后的当天结束，界面显示实际日期。一小时是现在至一小时后的排期开始时间（含边界）。正在做、正在进行的跨日时间段、逾期事项始终显示；只填日期的今天事项也保留。结束时间已过的待办/会议计为逾期。时间范围每 10 秒按 Asia/Shanghai 刷新，可用 agenda.timezone 改为其他 IANA 时区。

没有排期的任务有「未安排 N 项」入口，按 **b** 或点击该行展开/收起。范围外的已排期任务可按 **3** 返回全部。完成与取消仍用原来的 status 查询查看；查询、项目和依赖规则继续生效。视图不会修改任务时间或状态，也不会从标题猜排期。

按 **,** 打开设置：密度控制分组留白；「任务行间留白」可选 0 / 1 / 2 行，默认 0，兼容原布局。CLI 也可设置：

```sh
atd config set ui.line_spacing 1
atd config set ui.density comfortable
atd config set ui.banner full
atd config set agenda.view hour
```

原 ASCII 艺术保留在 full 横幅中：有效终端不少于 72 列、26 行时完整显示；较小窗口降为小字，少于 46 列或 18 行降为一行标题。字号放大后有效行列会减少，横幅会跟着降级。字体由终端控制（macOS Terminal 可用 ⌘+ / ⌘−），应用不修改全局终端字体或 profile。


## 完成后的收尾

成功完成后，原行用约 0.7 秒显示勾选和划线，再归入底部「已完成」。动画期间可继续输入和移动；临时反馈行不接受再次点击。这个窗口新完成的最近三项保留可见，历史默认收起，按 6 或点击分组标题展开，按 o 重开。回车或再次点击已完成行不会误重开。

外部 CLI 把开着的事项完成时，运行中的 TUI 会在文件刷新后给同样的一次反馈。首次加载的历史不播放，重复刷新不重播；撤销或重开会取消尚未结束的反馈。关闭完成动画后直接归入底部分组。

## 窗口与字号

视图、行间留白、布局、皮肤和横幅选择写入 ATD 配置。窗口位置、大小和字体属于所用终端，当前 Finder 启动器只是调用 Terminal 打开 ATD，并没有应用自己的窗口恢复记录。字体放大后终端有效行列减少，ASCII 会按有效尺寸降级。

本版没有启用未经验证的窗口恢复功能，也不修改 Terminal 全局默认值。正在使用的窗口保持原状。
