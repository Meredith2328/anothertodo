# anothertodo (`atd`)

一个**轻量命令行 TODO 工具**。核心主张：一行把任务写完，剩下的交给工具。

```bash
atd add "后天 买牛奶 很急 @18:30"
```

这一行同时完成了三件事：日期解析成后天、紧急度解析为"高"、设置后天 18:30 的 toast 提醒，**剩余的词"买牛奶"就是标题**。回车即存，无需表单。

## 它解决什么问题

待办工具最烦的是录入成本：填日期、选优先级、设提醒、打标签，一套表单点下来比做这件事还累。atd 用**模糊输入**把成本压到一行——你平时怎么随口跟同事说，就怎么输入：

```
atd add "下周五 下午2点半 交季度报告 非常急 #工作 proj:q3 @14:00:toast,email"
```

日期、时间、紧急度、标签、项目、提醒全部自动识别，所见即所得（输入时有实时预览）。

## 核心特性

| 特性 | 说明 |
|---|---|
| **一行模糊输入** | 中文/英文相对日期、时间段、紧急度短语、`#标签` `proj:` `^父` `~等待` `@提醒`、`*重复`、`>>备注` 全自动解析 |
| **全屏 TUI** | 直接敲 `atd` 进入。分组清单、键盘/鼠标操作、实时预览、帮助面板 |
| **CLI 子命令** | `add` `list` `done` `edit` `show` `undo` `archive` `sync` 等，可脚本化 |
| **定时提醒** | 后台守护进程，Windows toast / 邮件 / 自定义 hook，错过补发、失败重试 |
| **git 多端同步** | 各端本地写、按需 sync 冲突合并，无服务端依赖，数据私有 |
| **优先级双模式** | 档位模式（levels）+ TaskWarrior 式加权（urgency），随时切换 |
| **重复任务与子任务** | `*每天` 这类规则完成时自动滚动生成下一条；`^父id` 的子任务在列表和 TUI 里缩进显示，支持多层 |
| **中英双语** | 议程分组、日期列、字段名表可切成英文（`[ui] lang`）；一行输入和查询语法两种语言完全一样 |

## 平台支持

Node.js 22+ 实现，三端通用（Windows / macOS / Linux）。数据格式是纯文本 `JSONL`，可读、可手改、可 `git` 版本化。
