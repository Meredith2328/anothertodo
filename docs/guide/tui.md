# 全屏界面 (TUI)

直接敲 `atd`（无参数）进入全屏 TUI。这是日常管理的主力界面——添加、完成、编辑、搜索都在一个界面里完成。

## 布局

![atd TUI 主界面](/screenshots/tui/main-list.png)

从上到下：

1. **横幅**：`ANOTHER TODO` 像素标题（终端过窄时自动缩小）。
2. **统计栏**（右上角）：排序模式、逾期数 `!N`、今日数 `●N`、活跃数 `∑N`、当前时间。
3. **任务清单**：按分组显示（逾期/今天/接下来/更远/等待中/无日期），选中行有高亮。列分别是：日期、TODO、紧急度、状态、标签/提醒。
4. **预览行**：`›` 开头，实时显示当前输入的解析结果，或操作反馈。
5. **输入框**：光标在这里输入。空时显示占位提示。
6. **底部 Footer**：`? 帮助 · i 输入 · d 完成 · q 退出`（可点击）。

## 快速上手：直接打字添加

进入 TUI 后**直接打字**——任何非快捷键字符都会自动跳进输入栏，输入时下方实时预览，回车保存：

<pre class="terminal-output">› 后天 买牛奶 很急 @18:30        ← 输入
   → 2026-08-23 | 标题：买牛奶  [高] ⏰2026-08-23 18:30(toast)   ← 实时预览</pre>

回车后任务入库，继续打下一条。不需要按 `i` 进输入区——首字符不是快捷键时自动进入。

## 快捷键速查

### 清单区（默认焦点，光标在任务列表）

| 键 | 动作 |
|---|---|
| `j` `k` `↑` `↓` | 上下移动选择 |
| `g` / `G` | 跳到最上 / 最下 |
| `Enter` | 完成选中的任务（若已完成则重新打开） |
| `d` | 完成选中任务 |
| `x` | 删除选中任务（软删除，可撤销；先弹确认框） |
| `e` | 编辑选中任务 |
| `w` | 押后到明天 |
| `c` | 取消任务 |
| `o` | 重新打开 done / cancelled 的任务 |
| `s` | 提醒推迟 10 分钟 |
| `l` / `→` | 打开详情浮层：备注、提醒投递状态、父子任务；浮层里 `j`/`k` 翻上下一条，`e` 直接编辑 |
| `空格` | 打勾多选，顶栏显示 `◉N` |
| `Ctrl+A` | 全选本屏 |
| `PgUp` / `PgDn` | 上下翻页 |
| `u` / `r` | 撤销上一步 / 重载配置刷新 |
| `1` / `2` | 档位排序 / urgency 排序 |
| `t` | 日期列格式：相对 / 月日 / 完整 |
| 直接打字 | 跳进输入区添加；若首字是快捷键（如 d），先按 `i` |

有勾选时 `d` `x` `c` `w` `o` `s` 会批量执行。`Esc` 先清多选，再当退出的第一下。

### 输入区（光标在输入框）

| 键 | 动作 |
|---|---|
| `Enter` | 提交：添加 / 命令 / 搜索 / 编辑保存 |
| `Tab` | 补全 `#标签` 和 `proj:项目` |
| `Esc` | 清空输入并回到清单区 |
| `: xx` | 命令模式 |
| `/ xx` | 搜索过滤 |

### 区域切换

| 操作 | 说明 |
|---|---|
| 清单 → 输入 | 直接打字（非快捷键首字）· `i` · `:` · `/` · `e`（编辑） |
| 输入 → 清单 | `Enter` 提交后自动 · `Esc` 清空 · 空输入回车 |
| 想打 `d/x/q` 等开头的标题 | 清单区先按 `i` 进输入区，再打字 |
| 默认焦点 | 在清单区（无需 Tab；Tab 是输入区补全） |

### 通用

| 键 | 动作 |
|---|---|
| `?` / `F1` | 帮助面板（任意键关闭） |
| `Ctrl+Z` / `Ctrl+S` / `Ctrl+F` | 撤销 / 同步 / 搜索 |
| `q` / `Q` / 双击 `Esc` | 退出（`Ctrl+Q` 也可） |

> 以上三个 `Ctrl+组合键` 均经实测可用。`Ctrl+Q` 也可退出。

## 详情浮层

`l` 或 `→` 打开当前任务的详情浮层：备注、提醒投递状态、父子任务一目了然。浮层里 `j`/`k` 翻上下一条，`e` 直接编辑当前这条。

![详情浮层](/screenshots/tui/detail-overlay.png)

## 多选

`空格` 打勾多选，`Ctrl+A` 全选本屏，顶栏显示 `◉N`。

![空格多选](/screenshots/tui/multi-select.png)

## 删除确认

`x` 删除会先弹确认框，只认 `y` / `Enter`，其他键一律当取消。

![删除确认框](/screenshots/tui/delete-soft.png)

## 子任务与标记

`^父id` 记的子任务会缩进排在父任务下面（支持多层）。列表里带重复规则的任务会标 `↻每天` 这类记号，有备注的也有标记。

![子任务缩进](/screenshots/tui/subtasks.png)

## 帮助面板

按 `?` 或 `F1` 打开完整帮助，按任意键关闭。终端高度足够时显示完整版：

![帮助面板（完整版）](/screenshots/tui/help-full.png)

终端较矮时自动切换到紧凑版，保证弹窗完整可见：

![帮助面板（紧凑版）](/screenshots/tui/help-compact.png)

## 命令模式

在清单区按 `:` 进入命令模式（或输入区先按 `:`）。支持：

```
:list <查询>      过滤 / 清除
:undo             撤销
:sync             同步
:mode levels      切换档位排序
:mode urgency     切换 urgency 排序
:archive [天数]   归档
:cancel           取消
:meeting          标记为会议
:todo             退回待办
:wait <日期>      押后到指定日期
:snooze <分钟>    提醒推迟指定分钟
:quit             退出
```

<pre class="terminal-output">› :mode urgency        ← 输入
   urgency 排序          ← 反馈</pre>

## 搜索过滤

按 `/` 或直接输入 `/关键字` 回车，列表只显示匹配项，顶栏显示当前过滤条件：

![搜索过滤](/screenshots/tui/search-filter.png)

用 `:list`（空查询）清除过滤。查询语法见 [查询语法](/guide/query)。

## 编辑任务

列表上按 `e`：任务的全部字段被序列化回输入栏，直接改这一行（语法和添加完全相同），回车保存。

![编辑任务](/screenshots/tui/edit-task.png)

> 编辑是"写了才改"——解析出什么字段就覆盖什么字段，没写的字段保持原值。

## 日期列格式切换

按 `t` 在三种格式间循环：**相对日期**（今天/明天/后天）→ **月/日**（8/20）→ **完整日期**（2026-08-20）。

![日期格式切换](/screenshots/tui/date-format.png)

## 鼠标操作

TUI 支持鼠标：

- **点击任务行**：选中该行；**再点同一行** = 完成/重新打开。
- **点击 Footer 按钮**：触发对应快捷键（`?` 帮助、`i` 输入、`d` 完成、`q` 退出）。**任何模式下都能点**。
- **滚轮**：上下滚动选中行。

## 退出

- `q` / `Q`：直接退出
- 双击 `Esc`：有勾选时第一次 `Esc` 清空多选，之后按一次会提示"再按一次 Esc 退出"，1 秒内再按即退出
- `Ctrl+Q`：退出
